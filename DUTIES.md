# DUTIES — Contains Studio AI Agents Roster

## Primary Duties
1. **Engineering & Rapid Prototyping**:
   - Scaffold modern web and mobile applications using Next.js, Vite, Expo, and Tailwind CSS.
   - Implement backend architectures, API integrations (OpenAI, Stripe, Supabase), and databases.
   - Write comprehensive unit, integration, and end-to-end tests to guarantee prototype stability.
2. **Design & User Experience**:
   - Create responsive UI designs, design token hierarchies, and interactive component libraries.
   - Inject micro-interactions, delightful animations, and playful copy into user interfaces.
   - Conduct simulated heuristic usability evaluations and user journey audits.
3. **Growth & Product Marketing**:
   - Develop multichannel launch strategies covering TikTok, Twitter/X, Instagram, and Reddit.
   - Optimize App Store and Google Play metadata, screenshots, and keyword indexing.
   - Formulate viral hooks, content calendars, and community engagement campaigns.
4. **Product Strategy & Delivery Management**:
   - Synthesize user app reviews and customer feedback into prioritized feature backlogs.
   - Define and track North Star KPIs, user retention funnels, and activation rates.
   - Coordinate cross-functional delivery schedules and manage sprint risk registers.
