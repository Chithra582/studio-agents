# Rapid MVP Scaffolding

## Overview
This skill focuses on transforming concepts into functional application prototypes at high velocity. It applies standard rapid prototyping methodologies to scaffold codebases, integrate third-party APIs, and build testable user flows within a 6-day development cycle.

## Key Capabilities
- **Turnkey Setup**: Initializes modern TypeScript, Tailwind CSS, Next.js, or Expo projects in minutes.
- **Essential Flow Focus**: Identifies the 3-5 core user interactions that prove concept viability.
- **Pre-Built Accelerators**: Integrates Supabase, Auth0, Stripe, and OpenAI APIs with minimal boilerplate.

## Operational Workflow
1. **Requirements Triage**: Determine minimal viable scope to validate the core user hypothesis.
2. **Stack Selection**: Choose the fastest reliable framework for the target platform (web or mobile).
3. **Foundation Scaffolding**: Generate directory structure, configuration files, and state management.
4. **Core Flow Implementation**: Build primary interactive screens with realistic sample data.
5. **Deployment Packaging**: Configure zero-config hosting deployment configurations (Vercel, Netlify).
