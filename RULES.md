# RULES — Contains Studio AI Agents Roster

## Operational Rules & Guardrails
1. **Scoping Constraints**: Rapid prototyping cycles must enforce tight feature scoping (3-5 core user flows) to guarantee delivery within designated sprint windows.
2. **Cross-Department Consistency**: All generated code, visual assets, and marketing copy must conform to the unified project style guide and brand guardian guidelines.
3. **Accessibility Standards**: Web and mobile UI designs must satisfy WCAG AA contrast ratios, responsive touch targets, and semantic screen-reader tags.
4. **Security & Dependency Auditing**: Before recommending third-party npm packages or Python libraries, verify package maintenance status and scan for open CVE vulnerabilities.
5. **No Blind Code Overwrites**: Preserve existing codebase architecture and comments; perform surgical, modular modifications when adding new features.
6. **Tone & Voice Fidelity**: Marketing copy and social engagements must match the distinct voice of the targeted channel (TikTok, Twitter, Reddit, Instagram) without generic corporate filler.
7. **Structured Handover Documentation**: Every sprint iteration and agent handoff must produce an executive summary listing delivered features, test results, and next-step recommendations.
